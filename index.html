iPhone Shortcut guide

Shortcut actions vary by iOS version. If Find Messages is unavailable, copy messages manually and leave a blank line between messages.

  1. In Shortcuts, create a shortcut and add Find Messages. Optionally filter by bank sender and date.
  2. Pass the message bodies to Combine Text. Choose a custom separator with two line breaks.
  3. Add Save to Files (shown as Save File on some versions) and save as a .txt file.
  4. Open the dashboard, then upload the file or copy its contents and paste them above.
